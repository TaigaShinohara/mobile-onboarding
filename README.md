# Mobile Onboarding

モバイルアプリの初回オンボーディングを設計し、実装するためのスキルです。アプリの内容とコンセプトを深く理解した上で、ページ形式で「何のためのアプリか」と「基本的な使い方（スリーステップ）」を伝え、ワクワクしながら早く使いたいと思わせる初回体験をつくります。

## このスキルが守ること

| 原則 | 具体的なルール |
| --- | --- |
| 1ページ1主張 | 1画面に言いたいことを2つ以上載せない。ページ枚数は増えてよい。詰め込むより割る |
| コンセプトから作る | アプリの内容を読まずにページ案を作らない。コンセプトを一文で言えない場合は、候補を作って確認してから進める |
| スリーステップで使い方を届ける | 基本的な使い方はちょうど3ステップ、1ステップ1ページで示す |
| 見せて、参加させる | 図形・アイコン・アニメーションを全ページに入れ、選択や回答などのインタラクションを途中に散らす。答えは後の内容や初期設定に反映する |
| テンポよく、早く本体へ | スキップを常に見せ、説明で終わらず本体の最初の小さな成功へつなぐ。進捗は窓ドット（最大5つ表示）で示し、総ページ数を数えさせない |

## 達成したい4つ

1. 何のためのアプリかがわかること
2. 基本的な使い方がスリーステップでわかること
3. ワクワクすること
4. 早くアプリを使いたいと思わせること

## インストール

このリポジトリを取得し、`skills/mobile_onboarding` フォルダをスキルディレクトリへコピーしてください。

- Codex の場合は通常 `~/.codex/skills/` へコピーします。同名の既存スキルがある場合は、内容を確認してから置き換えてください。スキル一覧を更新するには、セッションの再起動が必要な場合があります。
- Muse の場合は `~/workspace/custom-skills/mobile_onboarding/` へコピーします。

## 使い方

対象アプリと、希望する範囲（設計まで、実装まで）を添えて依頼します。

> `$mobile-onboarding` を使って、このアプリのオンボーディングを作って。まずはコンセプトの読み取りとページ地図まで。

> `$mobile-onboarding` を使って、既存のオンボーディングを見直して。1ページ1主張、スリーステップ、インタラクションを入れて、実装と検証まで進めて。

## 内容

- `skills/mobile_onboarding/SKILL.md` — スキルの入口と手順（絶対のルール、コンセプトの読み取り、ページ地図、演出とインタラクション、実装と検証）
- `skills/mobile_onboarding/references/page-patterns.md` — 7つのページ型（フック／アイデンティティ／価値／ステップ／インタラクション／期待／接続）とテンポ・演出の設計
- `skills/mobile_onboarding/references/copy-guide.md` — 見出し、補足、スリーステップ、選択肢の文言の手引き
- `skills/mobile_onboarding/references/checklist.md` — 出荷前のチェックリスト（主張の数、4条件、テンポ、インタラクション、実装と運用、人間の確認）
- `skills/mobile_onboarding/agents/openai.yaml` — Codex 向け表示情報
- `evaluations/` — 架空の入力による回帰評価の手順と判定条件
- [CHANGELOG.md](CHANGELOG.md) — 版と変更履歴（現在の版は 0.2.0）
