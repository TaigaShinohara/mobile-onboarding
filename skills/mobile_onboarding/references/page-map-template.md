# ページ地図のテンプレート

ページ地図は、このスキルの中心成果物である。設計の段階でこの様式で作り、実装と検証の間もこの地図を正として扱う。

## 列の定義

| 列 | 書くこと |
| --- | --- |
| # | ページ番号（1始まり、表示順） |
| 役割 | ページ型のどれか（フック／選択／マッチ／アイデンティティ／価値／ステップ／インタラクション／期待／接続） |
| 主張 | そのページの主張そのものを、見出し1行で書く。主張が2つ書きたくなったら、ページを分ける |
| 補足 | 最大2行。書かなくて済むなら空けてよい |
| 視覚の主役 | 主張を伝える図形、アイコン、イラスト、画面モック、写真。1ページに1つ |
| 主役のアニメーション | 何を目立たせ、何を伝えるための動きか、の2点を書く。意味を書けない動きは入れない |
| その他のアニメーションと理由 | 主役以外に動くものがある場合だけ、その理由（内容を伝える／反応と称賛／誘導／つながりと状態）を書く。原則は「なし」。理由を書けない動きは入れない |
| 操作と遷移先 | 利用者ができる操作と、進んだ先。質問ページは「次へボタンなし、選択で自動遷移（次：○○）」と書く |
| 反応の段階 | 押下への反応の段階（小／中／大、または反応なしの理由） |

## 空の様式

| # | 役割 | 主張 | 補足 | 視覚の主役 | 主役のアニメーション | その他のアニメーションと理由 | 操作と遷移先 | 反応の段階 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | フック |  |  |  |  |  |  |  |
| 2 | 選択 |  |  |  |  |  |  |  |
| 3 | マッチ |  |  |  |  |  |  |  |

## 記入例（架空アプリ PhotoShelf、12ページ）

PhotoShelf：撮った写真を自動で棚に整理し、探さずに眺められるアプリ。

| # | 役割 | 主張 | 補足 | 視覚の主役 | 主役のアニメーション | その他のアニメーションと理由 | 操作と遷移先 | 反応の段階 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | フック | 撮るだけ。あとは、棚まかせ |  | 棚の図形 | 写真が数枚、棚へ吸い込まれて収まる（自動で整うことを伝える） | なし | スワイプ／タップ → 2 | 小 |
| 2 | 選択 | 写真で、困っていることは？ |  | 具体的な選択肢2つ＋「まだわからない」（3択） | 選択肢がごく小さく震える（ここを選んでほしいことを伝える） | なし（選択肢が主役のため） | 選択 → 反応と余韻（約1秒） → 自動遷移で 3（次へボタンなし） | 中 |
| 3 | マッチ | 「探すのに時間がかかる」あなたには、PhotoShelf がぴったり | 撮るだけで自動で並ぶから | 2つの図形 | 図形が寄って重なって1つになる（合うことを伝える） | なし | スワイプ／タップ → 4 | 中 |
| 4 | アイデンティティ | 探す人から、眺める人へ |  | 棚を眺める人物のアイコン | 人物の目線の先で棚が静かに開く（眺める体験を伝える） | なし | スワイプ／タップ → 5 | 小 |
| 5 | 価値 | 増えても、探さない | 日付と場面で、勝手に並びます | 日付の棚が並ぶ図 | 棚が1つずつ描かれて増える（勝手に増えて整うことを伝える） | なし | スワイプ／タップ → 6 | 小 |
| 6 | ステップ | 1. 撮る | いつもどおりで大丈夫 | カメラのアイコンと番号1 | 番号が切り替わり、シャッターの図が一度だけ光る（最初の手順を伝える） | なし | スワイプ／タップ → 7 | 小 |
| 7 | ステップ | 2. しまう | しまうのは棚の仕事 | 棚のアイコンと番号2 | 写真が棚へ収まる（しまう手順を伝える） | なし | スワイプ／タップ → 8 | 小 |
| 8 | ステップ | 3. 見つける | 開けば、もう並んでいます | 開いた棚のアイコンと番号3 | 棚が開いて中が見える（見つける手順を伝える） | なし | スワイプ／タップ → 9 | 小 |
| 9 | インタラクション | 試しに、1枚しまってみる | 本物の棚のミニ版です | サンプルの写真と棚 | 写真が指について動き、棚の近くで吸着する（本物の操作感を伝える） | なし | ドラッグでしまう → 10 | 中 |
| 10 | マッチ（結果） | しまった！ もう探さなくて大丈夫 | この1枚は、本物の最初の1枚になります | 収まった写真 | 一度だけ軽く広がって収まる（達成を伝える、800ミリ秒まで） | なし | スワイプ／タップ → 11 | 大 |
| 11 | 期待 | 最初の1枚から、棚は育ちます | たくさん入れるほど、眺めるのが楽しくなります | 小さな棚 | 棚が少しだけ育つ（これからの変化を伝える。誇張しない） | なし | スワイプ／タップ → 12 | 小 |
| 12 | 接続 | 最初の1枚を、入れてみる | 30秒で終わります | 「始める」ボタン | ボタンが静かに脈打つ（押してほしいことを伝える） | なし | 「始める」で本体の最初の成功へ | 大 |
