# 出荷前のチェックリスト

オンボーディングを渡す前の確認。1つでも必須項目が欠けたら、該当する工程へ戻して直す。

## 絶対のルール

- [ ] すべてのページで、主張がちょうど1つである（声に出して数える）
- [ ] 見出しが主張そのものになっていて、見出しだけ読んでも流れがわかる
- [ ] 補足が最大2行で、新しい主張を持ち込んでいない

## 4つの達成条件

- [ ] 何のためのアプリか：オンボーディングを見た人が、自分の言葉で一文で言える
- [ ] 基本的な使い方：ステップがちょうど3つで、3つだけで最初の操作が完結する
- [ ] ワクワク：途中に山場があり、最後の接続ページの前にも期待のページがある
- [ ] 早く使いたい：最後のボタンを押すと、本体の最初の小さな成功へ直結する

## テンポと見やすさ

- [ ] 静止したページがなく、全ページに何かしらのアニメーションがある
- [ ] すべての主役アニメーションに、目立たせる対象と伝える意味がページ地図に書かれている
- [ ] 常時アニメーションが1ページ2要素まで、振れ幅と周期が上限内に収まり、点滅や高速振動がない
- [ ] アニメーションを止めて見ても、そのページの主張が伝わる
- [ ] テキストだけのページがない（全ページに視覚の主役がある）
- [ ] 進捗が窓ドット（最大5つ表示）で示され、総ページ数が数えられない
- [ ] 1ページ進むごとにドットが必ず1つ動き、止まって見えるページがない
- [ ] 「3 / 10」のような数字の進捗表記が出ていない
- [ ] 読み上げで総数が読み上げられず、章名やステップ名で現在地が伝わる
- [ ] スキップと戻るが全ページで同じ場所にある
- [ ] 全体の完了時間がおおむね60〜120秒に収まり、標準フローでは90秒前後に寄っている
- [ ] 同じ強さ・同じ構図のページが3つ以上連続していない
- [ ] アニメーションは割り込み可能で、次へ進む操作を遅らせない
- [ ] 常時アニメーションが上限（1ページ2要素まで、振れ幅は数ピクセル・1〜2度・数パーセント程度、周期2〜4秒）を超えていない。点滅や高速振動、音の自動再生がない
- [ ] 文字サイズの拡大時と、動きを減らす設定で破綻しない

## 悩み・希望とマッチ宣言

- [ ] 質問と結果が別ページになっていて、質問のページに結果の文章が、結果のページに質問と選択肢が、同居していない
- [ ] 質問のページに「次へ」ボタンがなく、選択肢を押すと気持ちのいい反応の後に自動で次のページ（残りの質問、なければ結果のページ）へ進む
- [ ] 悩み・希望の選択ページがあり、質問は1ページ1問、選択肢はちょうど3つで、1つ目と2つ目が具体的な場面の文になっている
- [ ] 3つ目の選択肢が「その他」「まだわからない」に当たる逃げ道になっていて、その場合の宣言が断定になっていない
- [ ] マッチ宣言が、選んだ選択肢の言葉を映し、根拠の強みを1つだけ挙げている
- [ ] 宣言の後に来る価値の並びと、本体の最初の提案が、選んだ内容に合わせて変わる
- [ ] 宣言と補足に、結果を保証する言葉（必ず、絶対に、誰でも）が入っていない
- [ ] 質問がマッチ宣言までに最大2問に収まっている

## 押したときの反応（アニメーション・称賛・触覚）

- [ ] 意味のある押下すべてにアニメーションと触覚の返しがあり、中と大の場面では称賛の文も付いている（小では受け取りの印でよい）
- [ ] 強さが小・中・大の3段階に分かれ、完了の反応がいちばん大きく埋もれていない
- [ ] 称賛が具体的にしたことに触れていて、段階ごとに3通り以上あり同じ文が続かない
- [ ] スキップと戻るに、称賛も成功の触覚も付いていない
- [ ] 触覚がOS標準の機構で、端末の設定オフのときに鳴らない
- [ ] 動きを減らす設定で、弾みがフェードと文字の反応に置き換わる
- [ ] 反応の間も次の入力が塞がれていない
- [ ] 反応と次のページが同時に出ていない（現在のページで反応 → 余韻（タップから約1秒） → 遷移 → 次ページは見出し・主役・補足の順に入場、の順番になっている）
- [ ] 余韻の間にタップやスワイプをすると、待ちが打ち切られて即座に進む

## インタラクション

- [ ] インタラクションが最低2回、途中に散らして配置されている
- [ ] 1ページで聞くことが1つだけで、選択肢は3択（3つ目はその他系の逃げ道）、自由記述を求めていない
- [ ] すべての回答が、後の文言・すすめ方・初期設定のいずれかを変えている
- [ ] 回答の直後に、受け取った反応（タイプ、一言、つながり）が返る
- [ ] スキップが常に選べて、答えない人を責める文言がない
- [ ] 試し操作がある場合、その結果が本体の初期状態へ引き継がれる

## 実装と運用

- [ ] 完了状態が保存され、次回起動で表示されず、版が変わった場合だけ再表示される
- [ ] 権限と登録のページが、価値のページより後に置かれている
- [ ] システムのダイアログの前に、必要理由を示すアプリ内ページがある
- [ ] ページごとの表示・離脱・スキップ・回答が計測でき、個人を特定する内容を含まない
- [ ] 読み上げ順序が、見出し → 補足 → 視覚の説明 → 操作 の順になっている
- [ ] 主要な言語で見出しが主張1つのまま保たれ、レイアウトが崩れない

## 人間の確認

- [ ] 初見の人に通してもらい、直後に「何のためのアプリか」「最初に何をするか」「使ってみたいか」を聞いた
- [ ] その答えを記録し、4条件の判定に使った（AIの自己評価だけで判定していない）
- [ ] 未確認の項目は未確認として残し、成功に含めていない

## 差し戻しの目安

- 主張が2つ以上のページがある：ページ地図へ戻り、分割する
- 3ステップが3つに収まらない：コンセプトの読み取りへ戻り、初回の成功範囲を絞る
- ワクワクしないとの反応：価値のページと期待のページへ戻り、場面と視覚の主役から直す
- 離脱が多いページがある：そのページの主張・文言・演出の遅さを、この順で疑う
- 回答が使われていない質問がある：インタラクションの設計へ戻り、変化先を用意できない質問は外す
