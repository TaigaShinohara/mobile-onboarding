# 回帰評価

架空の入力で、このスキルの判断が崩れていないかを確認する手順です。実在のアプリや利用者のデータは使いません。

## 入力（架空）

架空のアプリ「PhotoShelf」を想定します。スマホ内の写真やファイルを、本棚のようにタグで整理して後からすぐ探せるローカル完結のアプリです。初回の成功は、写真を1つ選んでタグをつけ、本棚に並ぶところまでです。

依頼は「PhotoShelf のオンボーディングを作って。まずは設計案まで」とします。

## 判定条件

次のすべてを満たす場合のみ合格とします。

- コンセプトを読み取りの根拠とともに短く記録し、読み取れていない部分を未確認として分けている。
- ページ地図の全ページで、主張がちょうど1つである。2つ以上の主張を持つページがない。
- 基本的な使い方がちょうど3ステップになっている（例：選ぶ、タグをつける、本棚に並ぶ）。
- 全ページに視覚の主役があり、テキストだけのページがない。
- インタラクションが途中に2回以上あり、各回答が後の文言か初期設定を変える設計になっている。
- 権限や登録のページがある場合、それが価値のページより後に置かれている。
- 最後のページが、本体の最初の小さな成功（写真1つにタグをつける）へ直結している。
- 進捗が窓ドット（最大5つ表示）で示され、総ページ数が数えられず、1ページごとにドットが1つ動いている。
- 悩み・希望の選択（例：探すのに時間がかかる、など場面の選択肢）が1問あり、選択肢はちょうど3つで3つ目が「その他」「まだわからない」系の逃げ道になっていて、その言葉を映したマッチ宣言が続き、宣言後の価値の並びが選択に合わせて変わっている。
- 選択への反応と次のページが同時に出ていない（現在のページで反応 → 余韻 → 遷移 → 次ページは順番に入場、の順序になっている）。
- 質問と結果が別ページに分かれ、質問のページに「次へ」ボタンがなく、選択で気持ちのいい反応の後に自動で結果ページへ進んでいる。
- 全ページにアニメーションがあり、各主役アニメーションの意味がページ地図に書かれ、常時アニメーションは1ページ2要素まででノイズになっていない。
- 意味のある押下に段階（小・中・大）付きの反応が付き、アニメーションと触覚は全段階に、称賛の文は中と大に付いていて、スキップには称賛も成功の触覚も付いていない。
- 人間の体験確認が未実施であることを、成功に含めず未確認として残している。

## 不合格の例

- 1ページに「タグで整理できて、検索も速い」と2つの主張を載せた場合。
- 使い方が4ステップ以上に分かれ、統合の検討がない場合。
- 質問を置いたが、答えがどこにも反映されない場合。
- 最初のページで通知の許可を求めた場合。
- 10ページ分のドットをすべて表示し、総ページ数が数えられる場合。
- 悩みを選ばせたのにマッチ宣言がなく、後の並びも変わらない場合。
- 質問とその結果（マッチ宣言やタイプ表示）を同じページに表示した場合。
- 質問のページに「次へ」ボタンがあり、選んだ後に再度押させる場合。
- 静止したページがある場合、または常時アニメーションが3要素以上動き、主役より目立つ場合。
- 選択を押してもアニメーションも称賛も触覚も返らない場合、またはスキップにまで成功の触覚が付く場合。
- 選択肢が4つ以上ある場合、または3つ目が具体的な選択肢で逃げ道になっていない場合。
- 選択への反応（称賛）と次のページの内容がほぼ同時に出て、どちらも読めない場合。

## 追加ケース（0.5.0で追加）

### ケースB：総ページ数が5以下の小さなアプリ

入力：機能が1つだけの小さなアプリ（例：タイマー）。オンボーディングは4ページで足りる想定。

- 進捗は通常ドット（全ページ表示）でよい。無理に窓ドットにしない。
- ページ数が目安（10〜15）より少ないこと自体は不合格にしない。ただし、各ページの主張が1つに絞れているかは主ケースと同じに判定する。
- 悩み・希望の選択が成立しない場合は、無理に作らず、理由を記録して省略できる。

### ケースC：逃げ道（まだわからない）が選ばれた場合

入力：主ケースの選択ページで「まだわからない」を選んだ利用者を想定する。

- マッチ宣言が断定になっていない（「様子を見ながら、一緒に見つけましょう」のような誘いの言い方）。
- 宣言後の価値ページの並びは標準順のままで、無理に合わせた形になっていない。
- それでも本体の最初の成功へは直結している。

### ケースD：質問が2問ある場合

入力：悩みと希望の2問を聞く構成を想定する。

- 1問目を選ぶと結果ページではなく2問目のページへ自動で進み、2問目を選んで初めて結果ページ（2つを組み合わせた宣言）へ進んでいる。
- 質問ページのどちらにも「次へ」ボタンがない。
- 宣言は2つの答えを1文に組み合わせている。

### ケースE：動きを減らす設定が有効な端末

入力：OSの「視差効果を減らす／動きを減らす」が有効な状態を想定する。

- 常時アニメーションが止まり、主役の弾みが短いフェードと文字の反応へ置き換わっている。
- アニメーションを止めても、各ページの主張が伝わる。
- 触覚は端末設定がオフなら鳴らない。
